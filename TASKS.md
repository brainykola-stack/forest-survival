# Задачи и пожелания

Этот файл — рабочий список. Его можно править прямо на GitHub (карандаш справа сверху →
Commit changes), в том числе с телефона. Агент читает этот файл и открытые Issue перед работой.

## Как писать задачи

- Одна задача — один пункт списка.
- Пиши: **что сделать**, **где** (экран, файл, механика), **как понять что готово**.
- Приоритет помечай в начале: `[высокий]`, `[обычный]`, `[позже]`.
- Выполненное не удаляй — переноси в «Сделано», чтобы история не терялась.
