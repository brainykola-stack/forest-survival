# 99 Ночей в Диком Лесу

Браузерная 3D survival-horror игра на Three.js + TypeScript + Vite + Rapier.
Всё процедурное: лес, рельеф, постройки, монстры, звук. Внешних ассетов нет.

## Запуск

```bash
npm install
npm run dev
```

Открой `http://127.0.0.1:5199`.

Сборка и предпросмотр:

```bash
npm run build
npm run preview
```

## Что реализовано

**Мир.** Процедурная карта 400×400 м с seed: холмы, озеро, 7 зон (начальный лес, долина,
скалы, заброшенный лагерь, старая деревня, болото, глубокий лес). Деревья, камни, кустарники
и папоротники — через InstancedMesh; у стволов и крупных камней есть коллизии.

**Постройки.** 8 типов: хижины с интерьером, сторожевые вышки, лагерь с палатками, пещера,
развалины. Внутри есть мебель и свет.

**Выживание.** Здоровье, голод, выносливость, урон, смерть. Костёр с топливом, пламенем,
искрами, дымом, светом и звуком; гаснет и разжигается заново.

**Цикл суток.** Плавные переходы, солнце, луна, звёзды, туман, ночной гул. Длительность
дня/ночи и скорость настраиваются.

**Ночь за ночью.** Счётчик «Ночь N / 99», рост опасности, появление врагов ночью и уход утром.
Бонусные ночи за спасённых детей.

**Добыча и крафт.** Дерево, камень, волокно, ягоды, травы, металл. Инструменты (топор, кирка)
ускоряют и увеличивают добычу. 6 рецептов, часть требует рабочего стола.

**Инвентарь.** 24 слота, 4 быстрых, стопки, категории, использование еды и лекарств.

**Строительство.** Призрак объекта, проверка склона/пересечений/материалов, установка,
разборка с возвратом половины ресурсов, сохранение всех построек.

**Противники.** Четыре вида (Олень, Охотник, Ползун, Болотник) с моделями, анимацией ног,
конечными автоматами: покой, патруль, проверка шума, погоня, атака, поиск, возврат.
Есть проверка видимости, обход препятствий, реакция на свет и бег.

**Дети и сюжет.** Четверо детей в разных местах, диалоги, награды, счётчик спасённых;
6 записок с историей; оберег; две концовки в зависимости от находок.

**Задания.** 12 заданий трёх типов с прогрессом и защитой от повторного засчитывания.

**Случайные события.** Туман, шорохи, находки, появление фигуры ночью.

**Интерфейс.** Меню, лобби с готовностью и отсчётом, HUD, инвентарь, крафт, строительство,
пауза, настройки (громкость, чувствительность, качество, разрешение рендера, покачивание,
FPS, полный экран, скорость суток), экраны смерти и победы.

**Сохранение.** IndexedDB с версией формата и проверкой: ночь, время, игрок, инвентарь,
костёр, постройки, дети, записки, задания.

**Звук.** Полностью синтезированный Web Audio: ветер, птицы, ночной гул, шаги, удары,
огонь, рычание с панорамой, сердцебиение.

## Чего пока нет

- **Мультиплеер.** Кнопка честно сообщает, что сервер не запущен. Клиент вынесен в отдельный
  слой, но Socket.IO-сервер не реализован.
- **Внешние модели и текстуры.** Всё собрано из процедурной геометрии.
- **Уникальные события для каждой из 99 ночей.** Есть общая прогрессия и повторяющиеся события.
- **Полноценные интерьеры и пещеры с проходами.** Дома и пещера упрощены.
- **Анимации монстров уровня скелета.** Движение процедурное (качание конечностей).
